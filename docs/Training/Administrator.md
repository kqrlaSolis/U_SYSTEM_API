# Capacitación — Administrador (`Administrator`)

## Temario

1. Inicio de sesión y cambio de contraseña
2. Alta de usuarios y asignación de roles (módulos Users y Roles)
3. Edición de roles y permisos
4. Consulta de la bitácora (AuditLogs)
5. Parámetros del sistema (Settings)
6. Creación y cierre de periodos

## Permisos del rol

Ver `Security/RbacMatrix.md` (columna Administrador).

## Evaluación

- [ ] Ejecutó el flujo principal sin ayuda.
- [ ] Identifica qué hacer ante un error de permisos (403).
- [ ] Conoce el procedimiento de soporte.
